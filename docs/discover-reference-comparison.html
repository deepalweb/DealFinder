DealFinder: Uber Eats layout reference and Flutter implementation

This rebuild follows the concrete mobile layout in Uber's published screenshot: compact location header, rounded search, a single illustrated category strip, quick filter pills, large photography, open listing rows and a flat bottom tab bar.

Reference: Uber's April 2024 newsroom app screenshot. This is a public screen reference, not a hands-on review of the current signed-in app.

The Flutter screen keeps DealFinder's sapphire identity, real category IDs and working save/detail/filter/navigation flows. The original category drawings are native vectors. Uber logos and product artwork are not included in the app.
