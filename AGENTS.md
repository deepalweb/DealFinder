# DealFinder agent guidance

## Design reviews

For UI design reviews and improvements, follow `.design-rules/SKILL.md`.
Route topics with `.design-rules/references/hig-lookup.md` and read the relevant
`.design-rules/references/hig/*.md` files before giving design feedback.
For Flutter, also read `.design-rules/references/cross-platform.md`.
Apply Apple platform conventions to iOS; use the shared design and accessibility
principles for Android and the web while respecting their own platform conventions.

## UI implementation guidance

For visual design, UI implementation, and UX improvements, also follow
`.agents/skills/ui-ux-pro-max/SKILL.md`. Use its local search tool at
`.agents/skills/ui-ux-pro-max/scripts/search.py` with the relevant domain or stack
(Flutter for mobile; Next.js/React for the website).
Use Apple Design for applicable platform conventions and UI UX Pro Max for
product-specific visual direction and implementation guidance. Resolve conflicts
using the user's requirements and the target platform's conventions.
